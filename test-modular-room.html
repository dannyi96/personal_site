Modular Room Background Test
This test shows the new modular HTML/CSS room structure with both embedded objects and directly interactive furniture.

Features:
• Individual HTML elements for each furniture piece
• Some furniture elements are directly clickable (window, clock)
• Other objects are embedded within containers (desk items)
• Subtle hover effects without weird animations
• CSS flexbox for natural positioning
